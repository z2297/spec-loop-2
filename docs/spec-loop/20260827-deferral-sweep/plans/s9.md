# Slice s9 - Round 2: make the trigger-prose pins whitespace-tolerant

## Goal

Make s5's two prose pins (the fallback-agent trigger enumeration and the run-state-v2 trigger
union) match on whitespace-collapsed text, so s9's already-accepted round-suffix wording can
stay exactly as written and no future markdown rewrap can break the guard again.

## Architecture

`plugins/spec-loop/scripts/slice_wave_contract_base.py` holds shared source-contract anchors,
including `TRIGGER_PROSE_LEAD = "one of the seven triggers ("` and
`TRIGGER_UNION_PREFIX = '"trigger": "'`. Its only consumer for those two constants is
`test_slice_wave_contract_crash.py`, whose class `TestTheTriggerEnumAgreesAcrossAllSixHomes`
pins the six homes of the escalation-trigger enum. Two of those homes are markdown prose, and
the pins are byte-exact substring counts, so a hard-wrap of the pinned sentence drops the count
to zero. The fix is a single test-module-local helper that collapses runs of whitespace to one
space, applied to BOTH sides of every prose match; the constants and the prose stay untouched.

## Tech stack

Python 3 stdlib `unittest` + `re`, run via `python3 -m unittest discover`. Node `--test` for the
two `.mjs` segments. No new dependencies.

       def collapsed(text):
           """Runs of whitespace become a single space.

           A hard-wrap of markdown prose splits a pinned literal across a
           newline and drops its match count to zero. Both sides of every
           prose match below pass through here, so line breaks stay invisible
           to the pin and the prose stays free to rewrap.
           """
           return re.sub(r"\s+", " ", text)

   `re` is already imported in this module; add no new import.

3. Add the first regression test, as the LAST method of
   `class TestTheTriggerEnumAgreesAcrossAllSixHomes`:

       def test_the_prose_pin_survives_a_hard_wrap_of_the_fallback_sentence(self):
           # Every space becomes a line break: the harshest rewrap there is.
           rewrapped = FALLBACK_MD.read_text(encoding="utf-8").replace(" ", "\n")
           self.assertEqual(
               collapsed(rewrapped).count(collapsed(TRIGGER_PROSE_LEAD)), 1)

4. Add the second regression test, directly after it:

       def test_the_union_pin_survives_a_hard_wrap_of_the_contract_line(self):
           rewrapped = RUN_STATE_MD.read_text(encoding="utf-8").replace(" ", "\n")
           text = collapsed(rewrapped)
           prefix = collapsed(TRIGGER_UNION_PREFIX)
           self.assertEqual(text.count(prefix), 1)
           union = text.split(prefix, 1)[1].split('"', 1)[0]
           self.assertEqual(tuple(p.strip() for p in union.split("|")),
               self.triggers())

5. Run the segment again (own tool call) and confirm the two NEW tests fail with `0 != 1` -

   `test_the_fallback_agent_prose_lists_exactly_those_triggers` with:

           # enumeration a worker reads before it names a trigger. Located by
           # TRIGGER_PROSE_LEAD, whose own count word is pinned by the
