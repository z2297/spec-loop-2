### Measured resolver behaviour (probed directly, not recalled)

`measure_coverage._guarded_block` returns a contiguous run starting at the header and trims
only TRAILING blank lines. Probes: header+blank+indented → `[1,2,3]`; header+two indented →
`[1,2,3]`; header+indented+blank → `[1,2]`.

**Consequence that shapes this plan.** Once `len(resolved) == 2` holds, `resolved[1]` is
necessarily `resolved[0] + 1`, `resolved[0]` is necessarily the line `_MAIN_SHIM_RE` matched,
and `resolved[1]` is necessarily non-blank and indented. So contiguity, header-regex and body
assertions CANNOT FAIL — they are the same tautology being removed. The plan therefore ships
the length pin and nothing else of that family.
