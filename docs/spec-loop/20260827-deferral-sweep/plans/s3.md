**Goal.** Replace the self-referential substring assertions in
`plugins/spec-loop/scripts/test_run_metrics.py` with a test that feeds real v1

**Architecture.** `run_metrics.legacy_parse_escalations` splits a v1 `escalations.md`
into `## [token] …` blocks, and for each block `_legacy_body_fields` hands the text after
`- Trigger:` to `_legacy_match_triggers`, which lower-cases it and returns **every**
canonical trigger from `ESCALATION_TRIGGERS` that is a raw substring (no word
boundaries), in `ESCALATION_TRIGGERS` declaration order; a non-empty unmatched line
yields `["other"]` and an empty one `[]`. `legacy_parse_escalations` exposes the full
list as `triggers` and the first element as `trigger`. This slice adds a new
module-level v1 prose fixture in the exact `LEGACY_ESCALATIONS` shape plus test
methods in the existing `LegacyProseParserTests` class, which already drives that same
callable. **`run_metrics.py` is not modified by this slice.**

**Tech stack.** Python 3, stdlib `unittest` only. No new files.

1. Add the failing tests. Insert this fixture constant at the insertion point named above

   LEGACY_ESCALATIONS_CRASH = """\

2. Append these two methods to `LegacyProseParserTests` (they call the real public parser;
   the module-level fixture keeps the prose out of the method bodies):

   ```python
   def test_a_crash_trigger_line_matches_internal_error_through_the_real_parser(self):
       # Drives rm.legacy_parse_escalations -> _legacy_body_fields ->
       # _legacy_match_triggers on real v1 prose, so a change to the matcher's
       # containment semantics turns this red. ESCALATION_TRIGGERS is imported,
       # never re-listed here.
       escs = rm.legacy_parse_escalations(LEGACY_ESCALATIONS_CRASH)
       crash = escs[0]
       self.assertEqual(crash["triggers"], ["internal-error"])
       self.assertEqual(crash["trigger"], "internal-error")
       spurious = set(rm.ESCALATION_TRIGGERS) - {"internal-error"}
       self.assertEqual(set(crash["triggers"]) & spurious, set())

   def test_a_crash_trigger_line_alongside_budget_exhausted_collects_both(self):
       # _legacy_match_triggers collects every containment match, in
       # ESCALATION_TRIGGERS declaration order.
       escs = rm.legacy_parse_escalations(LEGACY_ESCALATIONS_CRASH)
       self.assertEqual(escs[1]["triggers"],
                        ["budget-exhausted", "internal-error"])
       self.assertEqual(escs[1]["status"], "OPEN")
   ```

   def test_the_trigger_names_are_pairwise_non_substrings(self):
