the `dag.json` data model: validated by `dag.py` only when present, documented in

`_load_for_mutation`. The reference doc and the coverage manifest are updated in lockstep with
the code, per this repo's single-home and manifest rules.

`unittest`, plain Markdown. No new files are created anywhere.
