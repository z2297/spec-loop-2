- Produces: a seventh `state` value, the exact string `'NO_USABLE_CEILING'`, with

  It carries `exceeded: []` and the real `thresholds` object (nulls included). It is a

**Design decision to implement exactly as written.** The new branch goes AFTER the `DISABLED`
check and BEFORE the `NOT_MEASURED` check. A mistyped ceiling is an operator-configuration
defect, and it must be reported as such even when the plan also declared nothing — checking
`NOT_MEASURED` first would blame the planner for a broken config and leave the config defect
invisible. This changes the reported state for exactly one input class (both ceilings null AND
both plan numbers null), from `NOT_MEASURED` to `NO_USABLE_CEILING`; both are fail-open, so no
halt behaviour moves. `min_rewritten_lines` is deliberately NOT part of the usability test: the
floor can only suppress a fire, so its absence never makes a ceiling unusable.
