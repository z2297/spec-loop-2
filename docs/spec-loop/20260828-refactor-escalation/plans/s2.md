### Chosen enum position (decided, not open)

`refactor-scope` goes at index 5, i.e. **after `quality-gate-block` and before
`budget-exhausted`**, in every home. Rationale to carry in the commit message: the first five
values are the judgment triggers whose answers are injected back into prompts, and
`budget-exhausted` / `internal-error` are the two deliberately non-judgment tail values. Placing a
new judgment trigger in the tail would split the judgment group and make
`ANSWERABLE_TRIGGERS` a non-prefix of the enum. The enum comparison is order-sensitive in
`test_the_workflow_enum_carries_exactly_those_values_in_order`, so this position must be
identical in all six homes.

Resulting canonical order (8 values):

```
ambiguity, material-assumption, review-block, council-objection, quality-gate-block,
refactor-scope, budget-exhausted, internal-error
```

`refactor-scope` contains no other trigger name and is contained by none, so
`test_the_trigger_names_are_pairwise_non_substrings` (`test_run_metrics.py:492`) and
`run_metrics._legacy_match_triggers` containment matching stay sound.
