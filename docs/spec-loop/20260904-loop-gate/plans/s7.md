## Why the gate blocked (so the fix is the right one)

`quality_gate.py`'s `_nesting_depth_python` derives nesting **from leading
whitespace**: `depth = (indent - base_indent) // 4`. In
`test_the_per_turn_flag_fact_is_confirmed_with_its_evidence`, the
visually-aligned continuation line `self.text)` sits at column 22, i.e.
`(22 - 4) // 4 == 4`, one over the `nesting_depth` threshold of 3. The fix is
therefore to remove the deep continuation indentation — hoisting the expected
substrings into module-level constants (module scope is not measured as function
nesting) — with the assertion set unchanged and no threshold touched.
